# NEON PLAYER X — V4 Professional Responsive

V4 focuses on a cohesive app-like UI, consistent inline SVG icons, micro-interactions, smoother section transitions and a native in-page radio player.

## Radio
The 12 featured stations use direct public stream endpoints where available, so NEON PLAYER X switches stations without leaving the page. If a provider blocks the stream in a browser, the official web button remains available as fallback.

Stations: LOS40, LOS40 Classic, LOS40 Dance, LOS40 Urban, Europa FM, KISS FM España, Radiolé, Rock FM, Radio MARCA, Deportes COPE, RAC1 and RNE Radio Nacional.

## Important
Public stream endpoints can change or impose browser/network restrictions. The application handles playback errors without opening a new page automatically.

NEON PLAYER X remains 0,99 € per unit.
